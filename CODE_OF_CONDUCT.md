# Code of Conduct

## Our Standards

DearOreUI is a technical project built around careful runtime research and reproducible engineering. Contributors are expected to:

- Be respectful, clear, and constructive.
- Discuss evidence, constraints, and trade-offs rather than people.
- Distinguish verified facts from hypotheses and design proposals.
- Welcome contributors with different experience levels and languages.
- Protect private user data, game data, and security reports.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate exposure of private information, and knowingly presenting unverified runtime behavior as fact.

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers may edit, hide, close, or remove contributions that violate this policy and may restrict participation when necessary to protect the project community.
